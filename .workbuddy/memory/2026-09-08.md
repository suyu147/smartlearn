## 关键实现约定
- 岗位视图不提供岗位下拉（避免与 career 模块耦合），靠 keyword 切换中心岗位：后端 `MATCH (r:JobRole) WHERE role_name CONTAINS keyword ORDER BY posting_count DESC LIMIT 1`
- 搜索框一个顶两个：即时做画布内高亮 + 450ms 防抖后作为 keyword 回源重新查询
- shadcn Select 不接受空字符串 → 用哨兵 `ALL='all'`，页面里 `norm()` 还原为 ''
- 后端 limit 合法区间 10–500，小于 10 会 422
- 节点半径：job 固定 32，其余 `clamp(10 + value/7, 10, 24)`；技能按 tier 分 core/advanced/bonus 三色
